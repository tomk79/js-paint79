# PSD の書き出し

## 概要

`exportPSD()` は、ドキュメントを Adobe Photoshop 形式(PSD)で書き出します。Photoshop をはじめとする、PSD を扱える外部アプリケーションで、レイヤーを保持したまま編集を続けるためのものです。

- PSD は外部アプリケーションとの受け渡し用の形式です。Paint79 の保存形式の正本は [Paint79 PNG](file-format.md) です
- PSD に書き出すと、一部の情報は失われます(後述の「失われる情報」)
- 現在のバージョンの `open()` は PSD を読み込めません。PSD を渡した場合は、[API 仕様](api.md#保存読み込み)のとおり、画像をデコードできないものとして `Error` で reject します
- 拡張子は `.psd`、MIME タイプは `image/vnd.adobe.photoshop` です

## 出力の形式

| 項目 | 値 |
| --- | --- |
| ファイル形式 | PSD(バージョン 1)。PSB(大きなドキュメント形式)は使わない |
| カラーモード | RGB |
| ビット深度 | 8 bit / チャンネル |
| 圧縮 | レイヤー画像、統合画像とも PackBits(RLE) |
| ピクセルサイズ | `max(1, round(width × pixelRatio))` × `max(1, round(height × pixelRatio))`(完成イメージと同じ) |
| 解像度 | 72 × `pixelRatio` ppi(Image Resource 1005) |
| カラープロファイル | sRGB の ICC プロファイルを埋め込む(Image Resource 1039) |

canvas の色は sRGB として扱われるため、sRGB のプロファイルを埋め込みます。プロファイルがない PSD を開くと、外部アプリケーションは作業用の色空間(Adobe RGB など)として解釈し、色がずれることがあるためです。

## レイヤーの対応

PSD のレイヤーは、Paint79 のレイヤーと同じく背面から前面の順に並べます。背景色がある場合は、その下に背景レイヤーを加えます(後述)。

| Paint79 | PSD |
| --- | --- |
| `name` | レイヤー名。Unicode のレイヤー名(付加情報 `luni`)に書く。互換用の Pascal 文字列には、ASCII 以外の文字を `?` に置き換え、先頭 255 文字までを書く |
| `visible` | 表示フラグ。`false` のレイヤーも、非表示のレイヤーとして書き出す |
| `opacity` | 不透明度。`round(opacity × 255)` |
| `blendMode` | 描画モード。下表 |
| `locked` | `true` の場合は「画像ピクセルのロック」(付加情報 `lspf` のビット 1)を設定する。`false` の場合はロックを設定しない |
| レイヤー画像 | 透明度と R・G・B の 4 チャンネル。色の値は、透明度で乗算していない値 |
| アクティブレイヤー | ターゲットレイヤー(Image Resource 1024)。値は背景レイヤーを含めた、最背面からのインデックス |

| `blendMode` | PSD の描画モード |
| --- | --- |
| `'normal'` | `norm`(通常) |
| `'multiply'` | `mul `(乗算) |
| `'screen'` | `scrn`(スクリーン) |
| `'overlay'` | `over`(オーバーレイ) |
| `'darken'` | `dark`(比較(暗)) |
| `'lighten'` | `lite`(比較(明)) |

### レイヤー画像の範囲

各レイヤーの画像は、透明でない(透明度が 0 でない)画素をすべて含む最小の矩形に切り詰めて書き出します。PSD のレイヤーは位置と大きさを持つため、こうすることでファイルサイズを抑えられます。

すべての画素が透明なレイヤーは、大きさ 0 × 0 のレイヤーとして書き出します。

### 背景色

背景色が `null` でない場合は、最背面に次の属性の通常のレイヤーを加え、キャンバス全体を背景色で塗りつぶします。

| 属性 | 値 |
| --- | --- |
| 名前 | `'背景'` |
| 表示 | 表示 |
| 不透明度 | 255(`1`) |
| 描画モード | `norm` |
| ロック | なし |

PSD には、Paint79 の「レイヤーではない背景色」に相当するものがないため、レイヤーとして表します。Photoshop の特殊な「背景」レイヤー(透明部分を持てないレイヤー)ではなく、通常のレイヤーです。

背景色が `null`(透明)の場合は、背景レイヤーを加えません。

## 統合画像

PSD の統合画像(Image Data セクション)には、[完成イメージ](document-model.md#完成イメージ)を書き出します。

- 完成イメージのすべての画素が不透明な場合は、R・G・B の 3 チャンネルで書き出します
- 透明度が 255 でない画素を含む場合は、R・G・B と透明度の 4 チャンネルで書き出します
  - 透明度のチャンネルが統合画像の透明度であることを示すため、レイヤー数を負の値で記録します
  - 色の値は、白の上に合成した値で書き出します。各チャンネルの値 `c` と透明度 `a`(`0`〜`255`)について、`round((c × a + 255 × (255 − a)) / 255)` です。完全に透明な画素は白になります。PSD を読み込むアプリケーションは、統合画像の色が白と合成されていることを前提としているためです

## 失われる情報

PSD に書き出すと、次の情報は失われます。

| 情報 | PSD での扱い |
| --- | --- |
| `pixelRatio` | 解像度(ppi)としてのみ残る。キャンバスサイズ(CSS ピクセル)は記録しない |
| レイヤー ID | 記録しない |
| 背景色 | 背景レイヤーになる |

## エラー

次の場合、`exportPSD()` は書き出しを行わずに reject します。

| 条件 | エラー |
| --- | --- |
| ピクセルサイズの幅または高さが 30,000 を超える(PSD の上限) | `RangeError` |
| PSD のセクションの長さが 2<sup>32</sup> − 1 バイトを超える | `Error` |
| `destroy()` の後に呼び出した | `Error` |

## 書き出す内容と描画中のストローク

`exportPNG()` と同じ規則に従います([API 仕様の「保存・読み込み」](api.md#保存読み込み-1))。

- 書き出す内容は、呼び出した時点の状態です
- 描画中の(まだ描き終えていない)ストロークは含めません
