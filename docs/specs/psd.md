# PSD の書き出しと読み込み

## 概要

`exportPSD()` は、ドキュメントを Adobe Photoshop 形式(PSD)で書き出します。Photoshop をはじめとする、PSD を扱える外部アプリケーションで、レイヤーを保持したまま編集を続けるためのものです。また `open()` は PSD を読み込み、レイヤーを 1 枚ずつ Paint79 のレイヤーとして復元します(後述の「読み込み」)。

- PSD は外部アプリケーションとの受け渡し用の形式です。Paint79 の保存形式の正本は [Paint79 PNG](file-format.md) です
- PSD に書き出すと、また PSD を読み込むと、一部の情報は失われます(後述の「失われる情報」「読み込みで再現されないもの」)
- 拡張子は `.psd`、MIME タイプは `image/vnd.adobe.photoshop` です

以下、「出力の形式」から「書き出す内容と描画中のストローク」までが書き出しの仕様です。

## 出力の形式

| 項目 | 値 |
| --- | --- |
| ファイル形式 | PSD(バージョン 1)。PSB(大きなドキュメント形式)は使わない |
| カラーモード | RGB |
| ビット深度 | 8 bit / チャンネル |
| 圧縮 | レイヤー画像、統合画像とも PackBits(RLE) |
| ピクセルサイズ | `max(1, round(width × pixelRatio))` × `max(1, round(height × pixelRatio))`(完成イメージと同じ) |
| 解像度 | 72 × `pixelRatio` ppi(Image Resource 1005)。PSD で表せる 1/65536〜32,767 ppi の範囲を超える場合は、その範囲に収める |
| カラープロファイル | sRGB の ICC プロファイルを埋め込む(Image Resource 1039) |

canvas の色は sRGB として扱われるため、sRGB のプロファイルを埋め込みます。プロファイルがない PSD を開くと、外部アプリケーションは作業用の色空間(Adobe RGB など)として解釈し、色がずれることがあるためです。

## レイヤーの対応

PSD のレイヤーは、Paint79 のレイヤーと同じく背面から前面の順に並べます。背景色がある場合は、その下に背景レイヤーを加えます(後述)。

| Paint79 | PSD |
| --- | --- |
| `name` | レイヤー名。Unicode のレイヤー名(付加情報 `luni`)に書く。互換用の Pascal 文字列には、ASCII 以外の文字を `?` に置き換え、先頭 255 文字までを書く |
| `visible` | 表示フラグ。`false` のレイヤーも、非表示のレイヤーとして書き出す |
| `opacity` | 不透明度。`round(opacity × 255)` |
| `blendMode` | 描画モード。下表 |
| `locked` | `true` の場合は「画像ピクセルのロック」(付加情報 `lspf` のビット 1)を設定する。`false` の場合はロックを設定しない |
| レイヤー画像 | 透明度と R・G・B の 4 チャンネル。色の値は、透明度で乗算していない値 |
| アクティブレイヤー | ターゲットレイヤー(Image Resource 1024)。値は背景レイヤーを含めた、最背面からのインデックス |

| `blendMode` | PSD の描画モード |
| --- | --- |
| `'normal'` | `norm`(通常) |
| `'multiply'` | `mul `(乗算) |
| `'screen'` | `scrn`(スクリーン) |
| `'overlay'` | `over`(オーバーレイ) |
| `'darken'` | `dark`(比較(暗)) |
| `'lighten'` | `lite`(比較(明)) |

### レイヤー画像の範囲

各レイヤーの画像は、透明でない(透明度が 0 でない)画素をすべて含む最小の矩形に切り詰めて書き出します。PSD のレイヤーは位置と大きさを持つため、こうすることでファイルサイズを抑えられます。

すべての画素が透明なレイヤーは、大きさ 0 × 0 のレイヤーとして書き出します。

### 背景色

背景色が `null` でない場合は、最背面に次の属性の通常のレイヤーを加え、キャンバス全体を背景色で塗りつぶします。

| 属性 | 値 |
| --- | --- |
| 名前 | `'背景'` |
| 表示 | 表示 |
| 不透明度 | 255(`1`) |
| 描画モード | `norm` |
| ロック | なし |

PSD には、Paint79 の「レイヤーではない背景色」に相当するものがないため、レイヤーとして表します。Photoshop の特殊な「背景」レイヤー(透明部分を持てないレイヤー)ではなく、通常のレイヤーです。

背景色が `null`(透明)の場合は、背景レイヤーを加えません。

## 統合画像

PSD の統合画像(Image Data セクション)には、[完成イメージ](document-model.md#完成イメージ)を書き出します。

- 完成イメージのすべての画素が不透明な場合は、R・G・B の 3 チャンネルで書き出します
- 透明度が 255 でない画素を含む場合は、R・G・B と透明度の 4 チャンネルで書き出します
  - 透明度のチャンネルが統合画像の透明度であることを示すため、レイヤー数を負の値で記録します
  - 色の値は、白の上に合成した値で書き出します。各チャンネルの値 `c` と透明度 `a`(`0`〜`255`)について、`round((c × a + 255 × (255 − a)) / 255)` です。完全に透明な画素は白になります。PSD を読み込むアプリケーションは、統合画像の色が白と合成されていることを前提としているためです

## 失われる情報

PSD に書き出すと、次の情報は失われます。読み込んだ後に Paint79 PNG で保存し直しても、元には戻りません。

| 情報 | PSD での扱い |
| --- | --- |
| `pixelRatio` | 解像度(ppi)としてのみ残る。キャンバスサイズ(CSS ピクセル)は記録しない |
| レイヤー ID | 記録しない |
| 背景色 | 背景レイヤーになる |

## エラー

次の場合、`exportPSD()` は書き出しを行わずに reject します。

| 条件 | エラー |
| --- | --- |
| ピクセルサイズの幅または高さが 30,000 を超える(PSD の上限) | `RangeError` |
| PSD のセクションの長さが 2<sup>32</sup> − 1 バイトを超える | `Error` |
| `destroy()` の後に呼び出した | `Error` |

## 書き出す内容と描画中のストローク

`exportPNG()` と同じ規則に従います([API 仕様の「保存・読み込み」](api.md#保存読み込み-1))。

- 書き出す内容は、呼び出した時点の状態です
- 描画中の(まだ描き終えていない)ストロークは含めません

## 読み込み

`open()` に PSD を渡すと、レイヤーを 1 枚ずつ Paint79 のレイヤーとして読み込みます。Paint79 が書き出した PSD だけでなく、他のアプリケーションが書き出した PSD も対象です。

Paint79 のドキュメントモデルにない要素(グループ、マスク、効果など)は、正しく再現されない場合があります。その場合でも、レイヤーを統合することはせず、レイヤーごとに処理します(後述の「読み込みで再現されないもの」)。表示が元のファイルと異なっていても、利用者が保存しなければ元のファイルは変更されません。

### 判定

ファイルの先頭 4 バイトが `8BPS` であれば PSD として扱います。PSD(バージョン 1)と PSB(バージョン 2、大きなドキュメント形式)の両方を読み込みます。

`Paint79.hasData()` は、Paint79 PNG のレイヤー情報を判定するものです。PSD に対しては `false` を返します。

`loadImage()` は PSD に対応しません。PSD を渡した場合は、画像をデコードできないものとして `Error` で reject します。

### 対応するカラーモードとビット深度

| カラーモード | 扱い |
| --- | --- |
| RGB | そのまま読み込む |
| グレースケール | R・G・B を同じ値にして読み込む |
| CMYK | 簡易的な計算で RGB に変換して読み込む(色は正確ではない) |
| ビットマップ、インデックスカラー | レイヤーを持たない形式のため、統合画像を読み込む(`'no-data'`) |
| Lab、ダブルトーン、マルチチャンネル | 対応しない。`Error` で reject する |

- 1 / 8 / 16 / 32 bit のファイルを読み込み、8 bit に変換します。16 bit は `round(値 / 257)`、32 bit はリニアな値として扱い、ガンマ 2.2 で変換します(`round(min(1, max(0, 値)) ^ (1 / 2.2) × 255)`。透明度は `round(値 × 255)`)
- 埋め込まれた ICC プロファイルは解釈せず、色の値を sRGB とみなします。Adobe RGB などで作成したファイルは、色がずれて表示されます

### キャンバスとレイヤーの配置

- キャンバスサイズは、通常の画像と同じく、PSD のピクセルサイズを読み込み先のインスタンスの `pixelRatio` で割った値になります
- 各レイヤーの画像は、PSD に記録された位置に、PSD の 1 ピクセルがキャンバスの内部解像度の 1 ピクセルになるように配置します。キャンバスの外にはみ出した部分は切り捨てます
- 背景色は `null`(透明)にします。PSD には Paint79 の背景色に相当するものがないため、PSD の透明部分をそのまま再現します
- 名前が「背景」のレイヤー(Paint79 が書き出した背景レイヤーを含む)も、通常のレイヤーとして読み込みます。背景色には戻しません

### レイヤーの属性

| PSD | Paint79 |
| --- | --- |
| レイヤー名 | `name`。Unicode のレイヤー名(`luni`)があればそれを使い、なければ Pascal 文字列を使う |
| 表示フラグ | `visible` |
| 不透明度 | `opacity`(`0`〜`255` を `0`〜`1` に変換) |
| 描画モード | `blendMode`。`norm` / `mul ` / `scrn` / `over` / `dark` / `lite` 以外は `'normal'` として読み込む |
| ロック(`lspf`) | 「画像ピクセルのロック」または「すべてをロック」が設定されていれば `locked: true`。それ以外のロック(透明部分、位置など)は `false` |
| ターゲットレイヤー(Image Resource 1024) | アクティブレイヤー。値は、グループの区切りを含む PSD のレイヤーレコードの並び(最背面から)のインデックスとして解釈する。通常のレイヤーを指していない場合や、記録がない場合は、最前面のレイヤーをアクティブレイヤーにする |

レイヤーの通し番号、履歴の破棄など、そのほかの扱いは Paint79 PNG を開く場合と同じです([API 仕様の「保存・読み込み」](api.md#保存読み込み-1))。

### 読み込みで再現されないもの

| 要素 | 扱い |
| --- | --- |
| グループ(フォルダ) | グループを解体し、中のレイヤーを順に並べる。グループが非表示なら中のレイヤーも非表示とし(入れ子の場合はいずれかの祖先が非表示なら非表示)、グループの不透明度は中のレイヤーの不透明度に掛け合わせる。グループの描画モードは無視する |
| レイヤーマスク | 有効な(無効化されていない)画素のマスクは、レイヤーの透明度に掛け合わせる。マスクの範囲外は、マスクの既定の色(`0` または `255`)を使う。マスクとしては残らない |
| ベクトルマスク | 無視する |
| クリッピングマスク | 無視する(クリッピングされていないレイヤーとして読み込む) |
| レイヤー効果(ドロップシャドウ等) | 無視する |
| 塗りの不透明度 | 無視する(レイヤーの不透明度だけを使う) |
| テキストレイヤー、スマートオブジェクト、塗りつぶしレイヤー | PSD に保存されている画素を、通常のレイヤーとして読み込む |
| 調整レイヤーなど、画素を持たないレイヤー | 名前と属性だけを持つ、空のレイヤーとして読み込む |

### 読み込みの結果

| 状況 | 結果 |
| --- | --- |
| レイヤーを読み込めた | `{ restored: true }`。上表の要素を含む場合も同じ |
| レイヤーを持たない PSD(統合済みのファイル、ビットマップ、インデックスカラー) | 統合画像を `'レイヤー 1'` という名前の 1 枚のレイヤーとして読み込み、`{ restored: false, reason: 'no-data' }`。背景色は変更しない |
| レイヤーの画像データが壊れているが、統合画像は読める | 統合画像を 1 枚のレイヤーとして読み込み、`{ restored: false, reason: 'corrupted' }`。背景色は変更しない |
| ファイル全体を解析できない、対応しないカラーモード、統合画像も読めない | `Error` で reject する。キャンバスの状態は変更しない |

- `ignoreMismatch` オプションは、PSD では使いません
- レイヤーを読み込む前に、読み込み先のインスタンスで確保するレイヤー画像のピクセル数の合計(グループを解体した後のレイヤー数。レイヤーを持たない場合は 1)が、[API 仕様](api.md#保存読み込み-1)の上限(268,435,456)を超えないことを、画像をデコードせずに検証します。超える場合は `Error` で reject し、キャンバスの状態は変更しません
