# ドキュメントモデル

Paint79 が扱うデータの構造と、各仕様で共通して使う用語を定義します。

## ドキュメント

1 つの `Paint79` インスタンスは、1 枚の絵(ドキュメント)を扱います。ドキュメントは次の要素で構成されます。

| 要素 | 説明 |
| --- | --- |
| キャンバスサイズ | `width`, `height`(CSS ピクセル) |
| 内部解像度の倍率 | `pixelRatio`。canvas およびレイヤー画像の実ピクセルサイズは `round(width × pixelRatio)` × `round(height × pixelRatio)` |
| 背景色 | `background`。すべてのレイヤーの下に敷かれる単色。`null` の場合は透明。背景色はレイヤーではない |
| レイヤーの配列 | 配列の先頭(インデックス `0`)が最背面、末尾が最前面 |
| アクティブレイヤー | ペンや消しゴムの描画対象となるレイヤー。常にいずれか 1 枚のレイヤーを指す |

初期状態では、空のレイヤーが 1 枚だけ作成され、それがアクティブレイヤーになります。

ドキュメントには常に 1 枚以上のレイヤーが存在します。最後の 1 枚を削除することはできません。

## レイヤー

各レイヤーは、キャンバスと同じピクセルサイズの、アルファチャンネル付きの画像を 1 枚持ちます。レイヤーの属性は [API 仕様の `LayerInfo`](api.md#layerinfo) で定義します。

- **消しゴム**は、アクティブレイヤーの描画内容を透明に戻します(背景色で塗るのではありません)
- **ロック**(`locked: true`)されたレイヤーへの描画は受け付けません
- **非表示**(`visible: false`)のレイヤーは、画面にも完成イメージにも含まれません

## 完成イメージ

背景色の上に、表示中のレイヤーを背面から順に、各レイヤーの `opacity` と `blendMode` に従って合成した 1 枚の画像を「完成イメージ」と呼びます。画面に表示される内容、`toBlob()` / `toDataURL()` の出力、[Paint79 PNG](file-format.md) の画像本体は、いずれも完成イメージです。

## 履歴

ドキュメントの内容を変更する操作は履歴に記録され、アンドゥ/リドゥの対象になります。

| 履歴に記録される操作 | 履歴に記録されない操作 |
| --- | --- |
| ストロークの描画(ペン・消しゴム) | アクティブレイヤーの切り替え |
| レイヤーの追加・削除・複製・並べ替え・統合・属性変更・消去 | ツール・色・線の太さの変更 |
| `clear()`、`resize()`、`setBackground()` | 読み取り専用モードの切り替え |
| `loadImage()` | |

- 1 回のストローク(ポインターを押してから離すまで)が 1 つの履歴になります
- 履歴の保持数は `historyLimit` で制限され、超えた分は古いものから破棄されます
- `open()` でドキュメントを読み込むと、履歴は破棄されます
- アンドゥした後に新しい操作を行うと、リドゥ可能な履歴は破棄されます

## 座標系

API およびイベントで扱う座標は、キャンバス左上を原点とし、右方向を `x`、下方向を `y` の正とする CSS ピクセル単位の値です。`pixelRatio` の影響は受けません。
