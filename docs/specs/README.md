# Paint79 仕様

このディレクトリの文書が、Paint79 の仕様の正本です。リポジトリ直下の [README.md](../../README.md) は、利用者向けにこれらの主要部分を抜粋したものです。両者が食い違う場合は、このディレクトリの記述が優先されます。

## 文書一覧

| 文書 | 内容 |
| --- | --- |
| [document-model.md](document-model.md) | ドキュメント・レイヤー・完成イメージ・履歴・座標系の定義と用語 |
| [api.md](api.md) | `Paint79` クラスの公開 API(コンストラクタ、オプション、メソッド、イベント) |
| [file-format.md](file-format.md) | 保存形式 Paint79 PNG のデータ形式 |
| [integration.md](integration.md) | Paint79 PNG を保存・表示するアプリケーションの開発者向けの要件と実装例 |

## 仕様の変更手順

1. 変更内容をユーザー(メンテナー)に提案し、合意を得る
2. このディレクトリの該当する文書を更新する
3. 利用者に影響する主要な変更であれば、[README.md](../../README.md) の抜粋も更新する
4. 変更した仕様に対するテストを書き、実装する([AGENTS.md](../../AGENTS.md) の TDD の手順に従う)

仕様の変更と、それに対応する README の変更は、同じコミットに含めてください。

## 記述のルール

- 公開 API は、ここに記載されたものがすべてです。記載のない公開 API を実装してはいけません
- 用語は [document-model.md](document-model.md) の定義に従います
- 新しい観点の仕様(例: 新しいツール、入力デバイスの詳細な扱い)が増えて既存の文書に収まらなくなった場合は、文書を追加し、この一覧に登録してください
- [file-format.md](file-format.md) の変更は、既存の Paint79 PNG の読み込み互換性に影響します。変更する場合は、形式バージョンと互換性の扱いを必ず併記してください
